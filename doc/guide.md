# 小陈待办 需求文档

## 1. 概述

- App 名称：小陈待办。
- 本地 todo App，手机端，**先做 Android**，后续再考虑 iOS。
- 技术选型：**React Native + Expo（development build）**，本地数据库，无后端。
- 无登录、无多设备云同步、不接入系统日历。
- 提醒使用**本地通知**：到期提醒 + 每日逾期汇总。
- 底部三个 tab：待完成 / 已完成 / 我的。

## 2. 页面结构

| 页面 | 入口 | 说明 |
|---|---|---|
| 待完成 | 底部 tab | 列表、排序、筛选/搜索、滑动完成、长按多选删除；右上角日历入口 |
| 已完成 | 底部 tab | 列表、筛选/搜索、滑动取消完成、长按多选删除 |
| 我的 | 底部 tab | 统计、类型管理、设置 |
| 新建 todo | 待完成页右下角 FAB | 表单底部「创建」 |
| todo 详情 | 点击 todo | 编辑、保存、删除 |
| 类型管理 | 我的 | 类型树 |
| 添加类型 | 类型管理 | 底部「创建」 |
| 编辑类型 | 类型管理 | 底部「保存」 |
| 日历视图 | 待完成右上角 | 按月查看待完成 todo |
| 设置 | 我的 | 提醒开关、汇总时间、权限状态 |

## 3. 数据模型

| 实体 | 字段 |
|---|---|
| Todo | id、名称、类型 id、优先级、预计完成时间（可空）、详情、创建时间、修改时间、完成时间（可空） |
| Type | id、父类型 id、名称、图标、同级排序 |
| Settings | 提醒开关、每日汇总时间 |

- 优先级：P1 最高 / P2 高 / P3 中 / P4 低。
- 预计完成时间：选择到分钟，存储到秒；非必填。
- 时间戳：
  - 修改时间：修改属性或点击完成/取消完成时更新；无改动保存不更新。
  - 完成时间：完成时写入，取消完成时清空。
- 预置类型：公司、自我提升（阅读、健身）。仅首次启动生成，可改名、删除、排序。
- 类型层级不限制深度；同一父级下不允许重名。

## 4. 待完成

### 4.1 展示
- 每条展示：名称、类型（图标 + 名称）、优先级、预计完成时间。
- 逾期（预计完成时间 < 当前时间且未完成）时，时间标红并显示「逾期」。

### 4.2 排序
- 默认：优先级从高到低；同优先级按修改时间倒序。
- 可切换：优先级从高到低 / 优先级从低到高 / 创建时间从远到近 / 创建时间从近到远。
- 非优先级排序模式下，并列项同样按修改时间倒序兜底。
- 排序方式记住，重启 App 后保留。

### 4.3 完成
- 左右滑动均可完成；滑动超过 30% 宽度触发，并带触感反馈。
- 完成/取消完成只能通过列表滑动；**详情页不提供完成操作**。
- 不提供撤销。

### 4.4 删除
- 长按进入多选，选择后删除。
- 二次确认（显示删除条数）。
- 删除后 5 秒可撤销（全局单槽，见第 12 节）。

### 4.5 筛选与搜索
- 类型：单选；选中父类型时包含其自身及所有子孙类型。
- 关键词：名称、详情模糊搜索。
- 优先级：多选。
- 只看逾期：快捷开关，仅显示已逾期且未完成的 todo。
- 条件之间为 AND。
- 待完成与已完成的筛选/搜索彼此独立；单次启动有效，重启清空。
- 排序不受筛选影响。

### 4.6 新建
- 新建入口：待完成页右下角 FAB「＋」。
- 新建成功后：清空待完成的筛选和搜索，滚动定位到新条目并高亮 2 秒。

## 5. 已完成

### 5.1 展示与排序
- 每条展示：名称、类型（图标 + 名称）、优先级、完成时间。
- 按完成时间倒序，最近的在前。
- 展示全部已完成记录，分页加载；不支持排序切换。

### 5.2 筛选与搜索
- 支持类型、关键词、优先级，规则同待完成。
- 不提供「只看逾期」。
- 与待完成彼此独立；单次启动有效，重启清空。

### 5.3 取消完成
- 左右滑动均可取消完成；滑动超过 30% 宽度触发，并带触感反馈。
- 不提供撤销；取消完成后回到待完成。

### 5.4 删除
- 长按多选删除，二次确认（显示条数），删除后 5 秒可撤销。

## 6. 新建 todo

| 字段 | 规则 |
|---|---|
| 名称 | 必填；最多 100 字 |
| 类型 | 必填；可选任意层级（含父级）；一条 todo 只属于一个类型 |
| 优先级 | 必填；默认 P3 |
| 预计完成时间 | 非必填；选择到分钟；不能选过去时间；未设置时不预填默认时刻 |
| 详情 | 非必填；最多 200 字，保留换行 |

- 类型选择器：
  - 展示类型树；
  - 支持内联新建类型（图标、名称、父层级），创建完成后自动选中；
  - 内联新建的类型会保留，即使随后放弃本次 todo 编辑。
- 校验：点击底部「创建」时校验名称非空、类型已选；失败则停留并提示。
- 未保存返回：二次确认「放弃本次编辑？」。
- 创建成功：返回待完成，执行 4.6。

## 7. todo 详情 / 编辑

- 入口：点击待完成或已完成列表中的 todo。
- 字段：名称（必填）、类型（必填）、优先级（必填）、预计完成时间（非必填）、详情（≤200 字）。
- 底部「保存」主按钮：
  - 保存时统一校验；名称为空则提示「名称不能为空」，不保存、停留并保留输入。
  - 保存成功后返回来源列表；若条目不在可视区，滚动定位并高亮 2 秒。
  - 若保存后不再符合来源列表的筛选或搜索条件，返回时提示「已不符合当前筛选」，并提供「清除筛选」操作。
  - 无改动时按钮置灰；无改动保存不更新修改时间。
- 返回：有未保存修改时，二次确认「放弃本次修改？」。
- 删除：右上角「…」菜单 → 删除；二次确认，5 秒可撤销；删除成功后返回来源列表。
- 完成状态：详情页不提供完成/取消完成；展示只读状态（待完成 / 已完成 + 完成时间）。
- 预计完成时间选择规则同新建；编辑时若原值已过期，保留原值，不因打开选择器自动改动。

## 8. 我的

- 统计：总计 / 待完成 / 已完成；全局实时，不受筛选影响。
- 类型管理入口。
- 设置：
  - 提醒开关（默认开启）。
  - 每日逾期汇总时间（默认 10:00）。
  - 通知权限、精确闹钟权限状态；未授权时可跳转系统设置。
- 类似 GitHub 的贡献图后续再做。

## 9. 类型管理

### 9.1 类型树
- 按层级展示；每一层级支持添加子类型、删除。
- 右上角「＋」添加根层级类型。
- 支持同层拖拽排序。
- 删除：
  - 二次确认，提示该层级下共有 x 条 todo（含所有子孙类型、含已完成）和 y 个子类型。
  - 删除后 5 秒可撤销（全局单槽）。
  - 撤销恢复整棵子树、其下所有 todo，以及完成状态、完成时间、创建/修改时间和原排序位置。
  - 不恢复筛选条件。
  - 若恢复后与同级类型重名，自动加「（已恢复）」后缀并提示。

### 9.2 添加类型
- 字段：图标（内置图标集）、名称（必填，≤20 字）、父层级（可选「根层级」）。
- 校验：名称非空、同一父层级下不重名。
- 点击底部「创建」；成功后返回类型管理，新类型排在同级末尾。
- 有未保存内容时返回，二次确认「放弃本次编辑？」。

### 9.3 编辑类型
- 字段：图标、名称、父层级。
- 底部「保存」；保存时校验名称非空、同一父层级下不重名。
- 父层级禁止选择自身及其子孙；变更父层级后移动到新父级的末尾。
- 保存成功后返回类型管理；若类型不在可视区，定位并高亮 2 秒。
- 有未保存修改时返回，二次确认「放弃本次修改？」。
- 无改动时「保存」按钮置灰。
- 右上角「…」菜单 → 删除；二次确认，5 秒可撤销；删除成功后返回类型管理。

### 9.4 类型图标
- 内置图标集选择，不做上传。

## 10. 日历视图

- 入口：待完成 tab 右上角（日历图标）。
- 仅展示待完成 todo，按月展示。
- 每天展示当天预计完成的 todo 数量（圆点/数字）。
- 点击某天查看当天待完成 todo，点击 todo 进入详情。
- 逾期 todo 标红。

## 11. 提醒

- 仅使用本地通知，不接入系统日历。
- **到期提醒**：每个 todo 在预计完成时间点发送一条单独通知；点击进入该 todo 详情。
- **每日逾期汇总**：
  - 存在逾期 todo 时，每天 10:00（可在设置中修改）发送一条汇总通知。
  - 持续到所有逾期 todo 完成或删除。
  - 点击进入待完成 tab，清空其他筛选/搜索，并开启「只看逾期」。
  - 内容为汇总提示；App 未运行时无法更新精确条数。
- 权限：
  - 通知权限在首次保存带预计时间的 todo 时申请。
  - Android 需精确闹钟权限。
  - **通知权限或精确闹钟权限未授予时，不发送任何提醒**；设置页显示状态并可跳转系统设置。
- 重排与取消：
  - 修改预计完成时间、完成、取消完成、删除、撤销删除时，自动重排或取消对应提醒。
  - 无预计完成时间的 todo 不提醒。
  - 关闭提醒开关时取消所有提醒。
- 实现提示：每日汇总需要预排未来一段时间的通知，确保 App 关闭时也能触发（技术方案细化）。

## 12. 删除与撤销

- 所有删除入口（详情单条、列表多选、类型删除）：
  - 二次确认；
  - 删除后 5 秒可撤销。
- 撤销条全局唯一：仅保留最近一次删除；新的删除覆盖旧撤销。
- 撤销条跨 tab / 页面保留；App 重启后失效。
- 撤销恢复删除前的完整状态（含完成状态、时间戳、原排序位置）。
- 完成/取消完成不提供撤销。

## 13. 通用约定

- 名称 100 字、类型名 20 字、详情 200 字，输入时截断。
- 搜索不区分大小写，只匹配名称和详情，不搜索类型名。
- 类型筛选父级包含自身及子孙；筛选子类型不包含直接挂在父类型上的 todo。
- 类型选择器内联新建仅出现在新建/编辑 todo 中；筛选、父层级选择器不提供。
- 内联新建类型：父层级默认「根层级」，未选图标时给默认图标，创建后追加到同级末尾。
- 统计始终全局，不受筛选影响。
- App 启动默认停留在待完成 tab。
- 多选模式下禁用滑动完成；切换 tab 或修改筛选时退出多选。
- 排序方式重启保留；筛选、搜索、「只看逾期」重启清空。
- 数据仅存本地；卸载/换机不保留，本期不做导入导出。
- 无登录、无云同步、不接入系统日历。

## 14. 技术约束

- Android 12 起（API 31）；React Native + Expo（development build / prebuild）。
- Android package：`com.curechen.todo`。
- 本地数据库；无后端。
- 本地通知：到期提醒 + 每日逾期汇总。
- Android 权限：通知权限、精确闹钟权限、开机恢复；权限不足时不提醒。
- iOS 后续再做；届时处理 64 条待发通知上限。
- 详细技术方案见 [tech-plan.md](./tech-plan.md)。

## 15. 暂不做

- iOS 端。
- 登录、多设备云同步。
- 系统日历集成。
- 贡献图 / 复盘报表。
